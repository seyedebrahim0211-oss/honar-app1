# اپ اندروید جان‌فدا | هنر مردمی

**نسخهٔ کد 1.0.0+1 | Flutter — آمادهٔ تلاش برای ساخت، نه APK تست‌شده.**

## آنچه پیاده‌سازی شده است

- ثبت حضوری آنلاین و آفلاین؛ نام، نام خانوادگی، نام پدر، تلفن، تاریخ تولد، شهر، نشانی، حوزه فعالیت، توضیحات و رضایت.
- دوربین زنده با کادر بیضی چهره و راهنمای موقعیت: یک صورت، روبه‌رو، مرکز کادر، نور مناسب و شاخص شارپنس.
- پس از **۳ فریم معتبر متوالی** کادر و دکمه عکاسی سبز می‌شوند. بعد از ثبت عکس نیز چهره و کیفیت تصویر دوباره کنترل می‌شود.
- پردازش چهره روی دستگاه با ML Kit: تشخیص حضور چهره، **نه شناسایی هویت**؛ در صورت خطا امکان تکرار عکاسی وجود دارد.
- فایل‌های JPEG عکس در مخزن خصوصی اپ با AES-256-GCM رمزنگاری می‌شوند؛ داده‌ها در SQLCipher نگهداری می‌شوند.
- PIN محلی شش‌رقمی، قفل دوباره پس از بیش از ۲ دقیقه حضور در پس‌زمینه؛ کد اتصال مسئولان در Android Secure Storage.
- همگام‌سازی دستی و خودکار هنگام باز بودن اپ و بازگشت شبکه؛ جلوگیری از دوباره‌فرستی با شناسه UUID یکتا و بازیابی کد رهگیری واقعی از سرور.
- خروجی XLSX با فهرست کلی و یک شیت پرونده برای هر فرد؛ ZIP شامل همان اکسل به‌همراه فایل عکس هر پرونده.
- سیستم پیامک سایت: بعد از ثبت **موفق روی سرور**، عبارت زیر برای موبایل ثبت‌شده در صف WP-Cron ارسال می‌شود (از ملی پیامک تنظیم‌شده در سایت):

  «ثبت نام شما با موفقیت انجام گردید. به زودی با شما تماس گرفته خواهد شد.»

**نکته:** برای پرونده‌ای که فقط آفلاین روی گوشی ذخیره شده، پیامکی ارسال نمی‌شود. نتیجه واقعی تحویل پیامک وابسته به اعتبار پنل، خط فرستنده، فیلترهای اپراتور و وضعیت WP-Cron است و باید در میدانی تست شود.

## سایت و نگارفرم

- فرم اختصاصی: https://honarmardomi.ir/form/jan-fada/
- شناسه فرم: `8`
- مسیر ارسال استاندارد: `POST https://honarmardomi.ir/wp-json/negarform/v1/submit/8`
- مسیر بازیابی رسید: `GET https://honarmardomi.ir/wp-json/negarform/v1/janfada/receipt/{uuid}`
- هدر اتصال اختصاصی: `X-Janfada-Device-Key`.
- فیلدها: `first_name`, `last_name`, `father_name`, `mobile`, `birth_date`, `city`, `address`, `activity`, `photo`, `notes`, `device_uid`, `consent[0]`.
- بدون کد اتصال، دانلود رسید مجاز نیست و ارسال عمومی فرم با نرخ پایین نگارفرم محدود می‌شود؛ با کد اتصال معتبر، سهمیهٔ اختصاصی برای مسئولان پویش فعال است.
- فایل عکس در بخش خصوصی نگارفرم ذخیره می‌شود؛ در اکسل آنلاین هر نفر لینک دانلود احرازشده نمایش داده می‌شود.
- کد اتصال در **فایل جداگانه و محرمانهٔ** `janfada_operator_key.txt` ارائه شده است. **این فایل نباید به GitHub عمومی یا داخل APK افزوده شود**. مدیر باید کد را فقط به مسئولان مجاز بدهد. در اپ آیکون مسئول ثبت‌نام بالای صفحه، کد را وارد کنید.
- چون تغییرات API/پیامک مستقیماً در فایل‌های افزونهٔ نگارفرم سایت انجام شده، قبل از بروزرسانی آن افزونه باید تغییرات ادغام یا به افزونهٔ مستقل منتقل شوند.

## ساخت اندروید

پیش‌نیاز: Flutter 3.38+، Dart 3.10+، Java 17، Android SDK 36، اتصال اینترنت برای دریافت بسته‌ها. در ریشه پوشهٔ پروژه:

```bash
flutter create --platforms android --project-name jan_fada --org ir.honarmardomi .
flutter pub get
```

داخل `android/app/src/main/AndroidManifest.xml`، پیش از `<application>`:

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.CAMERA" />
<uses-feature android:name="android.hardware.camera" android:required="false" />
```

در همان `application` تنظیم `android:allowBackup="false"` و `android:usesCleartextTraffic="false"` را اضافه کنید و `minSdk = 24` را در `android/app/build.gradle.kts` قرار دهید. فایل `android/app/proguard-rules.pro` باید شامل این مورد باشد:

```pro
-keep class net.sqlcipher.** { *; }
```

```bash
flutter analyze --no-fatal-infos
flutter test
flutter build apk --debug
```

مسیر خروجی APK آزمایشی: `build/app/outputs/flutter-apk/app-debug.apk`.

در `.github/workflows/android-apk.yml` یک گردش‌کار برای GitHub Actions است که همهٔ مراحل فوق را انجام می‌دهد و خروجی **APK آزمایشی** تولید می‌کند. برای نسخه رسمی قابل بروزرسانی، امضای انتشار ثابت جداگانه لازم است؛ **کلید debug را برای انتشار عمومی استفاده نکنید**.

## امنیت و محدودیت‌های آزمون

- تشخیص چهره و شارپنس مبتنی بر برآورد است و باید روی مدل‌های مختلف گوشی و نور واقعی آزموده و کالیبره شود. این سیستم نه تأیید هویت است و نه تضمین کیفیت پرتره.
- اجرای Flutter analyzer/test و ساخت Android APK در محیط تهیهٔ این بسته امکان‌پذیر نبوده؛ وجود فایل‌های سورس و گردش‌کار، به معنی تست موفق APK نیست.
- اتصال فعلی از کد مشترک کارکنان استفاده می‌کند، نه حساب اختصاصی و ثبت رویداد به تفکیک هر مسئول. کد را در گوشی‌های ناشناس وارد نکنید. در صورت افشا باید کد سرور عوض شود.
- اطلاعات افراد و عکس‌ها شخصی هستند؛ حتماً رضایت آگاهانه و برای افراد زیرسن شرایط رضایت سرپرست را رعایت کنید.
- فایل XLSX/ZIP خروجی **رمزنگاری نشده** و حاوی داده شخصی است؛ ارسال آن صرفاً به مسئولان مجاز و نگهداری امن ضروری است.
- رمز شش‌رقمی هیچ مسیر بازیابی ابری ندارد؛ پاک کردن داده‌های اپ، پرونده‌های همگام‌نشده را حذف می‌کند.
- امکان ویرایش پرونده‌های ثبت‌شده در سایت از داخل اپ فعلاً وجود ندارد؛ ویرایش فقط تا قبل از همگام‌سازی فعال است.
- در صورت قطع اینترنت و بازگشت بعدی، همگام‌سازی خودکار هنگام **باز بودن اپ** انجام می‌شود و سرویس پس‌زمینه دائمی نصب نشده است.
